================================================================================
 .env 채우기 — Meta API 인증 정보 발급 안내
================================================================================

이 프로젝트를 돌리려면 .env 파일에 두 값이 필요합니다.

    ig_user_id     내 인스타그램 비즈니스 계정의 숫자 ID
    access_token   Meta 가 발급하는 열쇠 문자열 (EAA... 로 시작)

아래 5단계를 따라가면 두 값을 모두 얻습니다. 처음이면 20~30분 걸립니다.
문서 맨 아래에 자주 겪는 오류와 해결법을 정리해 두었습니다.


--------------------------------------------------------------------------------
 먼저 알아둘 것
--------------------------------------------------------------------------------

이 도구는 Business Discovery 라는 기능을 씁니다. "내 계정으로 로그인해서
남의 공개 정보를 본다"는 구조라, 다음 조건이 모두 맞아야 동작합니다.

  1. 내 인스타 계정이 "비즈니스" 또는 "크리에이터" 계정일 것
  2. 그 계정이 페이스북 페이지와 연결되어 있을 것
  3. 조회할 상대 계정도 비즈니스/크리에이터 계정일 것

상대가 개인 계정이면 조회되지 않습니다. 연령 제한이 걸린 계정도 나오지 않습니다.
이건 권한 문제가 아니라 Meta 의 정책이므로 우회할 방법이 없습니다.

돈은 들지 않습니다. 개발자 계정 등록과 앱 생성 모두 무료입니다.


--------------------------------------------------------------------------------
 1단계. 인스타 계정을 비즈니스로 바꾸고 페이스북 페이지에 연결
--------------------------------------------------------------------------------

이미 비즈니스 계정이고 페이지에 연결돼 있다면 2단계로 넘어가세요.

  1. 인스타그램 앱 → 프로필 → 오른쪽 위 메뉴 → 설정
  2. "계정 유형 및 도구" → "프로페셔널 계정으로 전환"
  3. 비즈니스 또는 크리에이터 선택
  4. 전환 중에 "페이스북 페이지 연결" 단계가 나옵니다.
     페이지가 없으면 그 자리에서 새로 만들 수 있습니다.

페이지 연결은 건너뛰지 마세요. Business Discovery 는 페이스북 페이지를 통해
인스타 계정에 접근하는 구조라, 연결이 없으면 4단계에서 ID 를 찾을 수 없습니다.

확인 방법: 인스타 설정 → "연결된 계정" 에 페이스북 페이지 이름이 보이면 됩니다.


--------------------------------------------------------------------------------
 2단계. Meta 개발자 계정 만들기
--------------------------------------------------------------------------------

  https://developers.facebook.com

  1. 오른쪽 위 "시작하기" 클릭
  2. 본인 페이스북 계정으로 로그인
  3. 휴대폰 번호 인증과 이메일 확인을 요구합니다
  4. 역할을 물으면 "개발자" 선택


--------------------------------------------------------------------------------
 3단계. 앱 만들기
--------------------------------------------------------------------------------

여기서 "앱"은 배포할 프로그램이 아니라, Meta 가 발급하는 권한 묶음의 이름입니다.
혼자 쓸 것이라도 반드시 하나 만들어야 합니다.

  https://developers.facebook.com/apps

  1. "앱 만들기" 클릭
  2. 사용 사례를 고르라고 하면 "비즈니스" 선택
  3. 앱 이름은 아무거나 (예: ig-crawler). 나중에 바꿀 수 있습니다.
  4. 만들어지면 좌측 메뉴 "앱 설정 → 기본 설정" 에서 두 값을 복사해 둡니다.

        앱 ID          (숫자)
        앱 시크릿      ("표시" 버튼을 눌러야 보임)

     이 둘은 5단계에서 토큰 유효기간을 늘릴 때 씁니다. 메모장에 잠깐 붙여 두세요.

  ※ 앱 시크릿은 비밀번호와 같습니다. 절대 공유하거나 커밋하지 마세요.


--------------------------------------------------------------------------------
 4단계. 토큰 발급 + ig_user_id 찾기
--------------------------------------------------------------------------------

Graph API 탐색기라는 웹 도구에서 두 값을 한 번에 얻습니다.

  https://developers.facebook.com/tools/explorer

[4-1] 권한 선택하고 토큰 만들기

  1. 오른쪽 위 "Meta 앱" 에서 3단계에서 만든 앱을 고릅니다
  2. 그 아래 "사용자 또는 페이지" 를 "사용자 토큰" 으로 둡니다
  3. "권한" 목록에서 아래 네 개를 체크합니다

        instagram_basic              인스타 계정 기본 정보 읽기
        instagram_manage_insights    좋아요·조회수 등 지표 읽기
        pages_read_engagement        연결된 페이스북 페이지 읽기
        pages_show_list              내 페이지 목록 보기

     비즈니스 관리자(Business Manager)를 통해 페이지 권한을 받은 계정이라면
     ads_read 도 함께 체크해야 합니다. 잘 모르겠으면 일단 넷만 하고,
     나중에 오류가 나면 그때 추가하세요.

  4. "액세스 토큰 생성" 클릭 → 페이스북 로그인 창이 뜨면 승인
  5. 위쪽 칸에 EAA... 로 시작하는 긴 문자열이 생깁니다. 이게 토큰입니다.

  ※ 지금 토큰은 1시간 뒤 만료됩니다. 5단계에서 60일짜리로 바꿉니다.

[4-2] 내 페이지 ID 찾기

  탐색기 가운데 주소 칸에 아래를 입력하고 "제출" 을 누릅니다.

        me/accounts

  응답에 페이지 목록이 나옵니다. 1단계에서 인스타와 연결한 페이지를 찾아
  그 "id" 값을 복사합니다.

        {
          "data": [
            {
              "name": "내 페이지 이름",
              "id": "123456789012345"      ← 이 값
            }
          ]
        }

[4-3] ig_user_id 찾기

  방금 복사한 페이지 ID 를 넣어 다시 제출합니다.

        123456789012345?fields=instagram_business_account

  응답의 instagram_business_account.id 가 찾던 값입니다.

        {
          "instagram_business_account": {
            "id": "17841400000000000"      ← 이게 ig_user_id
          },
          "id": "123456789012345"
        }

  이 값이 안 나오면 페이지와 인스타 계정이 연결되지 않은 것입니다.
  1단계로 돌아가세요.


--------------------------------------------------------------------------------
 5단계. 토큰 유효기간 60일로 늘리기
--------------------------------------------------------------------------------

4단계에서 받은 토큰은 1시간짜리라 크롤링 도중 끊깁니다.
아래 주소를 브라우저 주소창에 붙여넣고 세 곳을 바꿔 넣으세요.

  https://graph.facebook.com/v25.0/oauth/access_token
    ?grant_type=fb_exchange_token
    &client_id=여기에_앱_ID
    &client_secret=여기에_앱_시크릿
    &fb_exchange_token=여기에_4단계_토큰

  (실제로는 줄바꿈 없이 한 줄로 이어 붙여야 합니다)

응답이 이렇게 옵니다.

  {
    "access_token": "EAAG...",     ← 이게 60일짜리 토큰
    "token_type": "bearer",
    "expires_in": 5183944          ← 남은 초 (약 60일)
  }

이 access_token 을 쓰면 됩니다.

  ※ 60일이 지나면 다시 발급받아야 합니다. 달력에 표시해 두세요.
  ※ 남은 기간이 궁금하면 https://developers.facebook.com/tools/debug/accesstoken
    에 토큰을 붙여넣으면 만료일이 나옵니다.


--------------------------------------------------------------------------------
 6단계. .env 파일에 넣기
--------------------------------------------------------------------------------

프로젝트 폴더에서:

  cp .env.example .env

.env 를 열어 두 값을 채웁니다. 따옴표나 공백 없이 그대로 붙여넣으세요.

  ig_user_id=17841400000000000
  access_token=EAAG...

잘 됐는지 확인:

  python3 crawling.py --max 1

계정 하나에서 게시물 1건을 받아옵니다. 정상이면 data/posts.csv 가 생깁니다.

  ※ .env 는 절대 공유하거나 커밋하지 마세요. .gitignore 에 이미 등록돼 있습니다.


--------------------------------------------------------------------------------
 자주 겪는 오류
--------------------------------------------------------------------------------

"Unsupported get request" / 오류 코드 100
  → 상대 계정이 개인 계정이거나, 아이디 철자가 틀렸습니다.
     인스타 웹에서 instagram.com/아이디 로 접속해 실제로 있는지 확인하세요.
     비즈니스 계정인지도 함께 보세요 (프로필에 카테고리가 표시됩니다).

"(#10) Application does not have permission for this action"
  → 4단계 권한 중 빠진 게 있습니다. 특히 pages_read_engagement 를 자주 빠뜨립니다.
     비즈니스 관리자로 권한을 받은 계정이면 ads_read 도 추가하세요.
     권한을 바꿨으면 토큰을 새로 만들고 5단계도 다시 해야 합니다.

"Error validating access token: Session has expired"
  → 토큰이 만료됐습니다. 4~5단계를 다시 하세요.
     1시간 만에 만료됐다면 5단계(60일 연장)를 건너뛴 것입니다.

instagram_business_account 가 응답에 없음
  → 페이스북 페이지와 인스타 계정이 연결되지 않았습니다. 1단계로.

오류 코드 4 / 17 / 32 / 613 / 80002
  → 시간당 호출 한도(200회)를 넘었습니다. 최대 1시간 기다리면 풀립니다.
     crawling.py 는 사용률 85% 를 넘으면 스스로 70분 쉬었다 재개합니다.
